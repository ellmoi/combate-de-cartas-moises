# La Convergencia

La Convergencia es un juego de cartas y combate por turnos. El jugador prepara un equipo, elige una arena y se enfrenta a un equipo controlado por la CPU.

## Tecnologías

- HTML
- CSS
- JavaScript

## Cómo ejecutar

Abre la carpeta `la_convergencia_prototype` con Live Server y entra a `index.html`. También se puede abrir el archivo directamente, aunque un servidor local evita problemas con los módulos de JavaScript.

## Cómo jugar

1. Elige el modo Selección y Combate.
2. Selecciona cinco personajes.
3. Elige el personaje inicial y confirma el equipo.
4. Selecciona una arena.
5. Inicia el combate contra la CPU.

## Controles

Durante la batalla puedes usar ataque básico, habilidades, defensa, análisis o cambiar al personaje activo. Las barras superiores muestran la salud y la energía de ambos combatientes. El registro inferior conserva las acciones recientes.

## Sonidos

El juego está preparado para reproducir estos archivos dentro de `assets/sounds`: `attack.mp3`, `hit.mp3`, `defense.mp3`, `ability.mp3`, `victory.mp3`, `defeat.mp3` y `click.mp3`. Son opcionales y deben ser audios propios o con licencia libre.

## Proyecto

Proyecto universitario realizado como práctica de HTML, CSS y JavaScript Vanilla.
